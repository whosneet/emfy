Emfy — Support

Get help with Emfy, the free open-source EMF viewer for the Mac.

Contact

Email: hello@arrley.com — include the file if you can; a real file beats any description.

Issues: github.com/whosneet/emfy/issues — bug reports and rendering problems.

Which versions does Emfy support?

macOS 14.0 (Sonoma) or later. An iPhone and iPad version is coming in 3.0 (in development, not yet released).

Which files does Emfy open?

EMF (.emf) files, including ones that use EMF+ records. WMF (.wmf) and the gzip-compressed .emz and .wmz forms are coming in 3.0.

Previews or thumbnails aren't showing

On the Mac, launch the Emfy app once — macOS registers the Quick Look extensions from then on. If Finder still shows generic icons afterwards, log out and back in, and check that Emfy's extensions are enabled in System Settings (search for “Extensions”, then look under Quick Look).

A file renders wrongly or partially

Emfy renders what it can and lists anything it had to approximate or skip in the viewer. A few files store some of their drawing content in formats Emfy simplifies. For anything that looks wrong, email the file or open an issue and it becomes a test case for the next release.

Where do I get the latest version?

On the Mac, the latest release on GitHub always has the newest notarized Emfy.dmg, and the same version is on the Mac App Store.

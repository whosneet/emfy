# corpus/

Committed test files only. A file may live here only if it is **self-generated**
(our own exports from PowerPoint, Excel, LibreOffice Draw, etc.) or
**verifiably CC0/public domain**. Everything else — GPL-sourced test resources,
work-sourced files — belongs in the gitignored `corpus-local/` and is never
committed, screenshotted, or quoted in issues, commits, or docs.

## Manifest

Every `.emf` here was generated by us — either from an authored `.svg`
converted with LibreOffice headless (`soffice --convert-to emf`, LibreOffice
26.2.4.2 on macOS), or hand-authored byte-by-byte (marked below). LibreOffice's
exporter wraps output in a vestigial dual-mode EMF+ comment shell (header +
two rendering hints + EOF, no EMF+ drawing) and under-reports the header
`Records` field by one — both quirks are intentional test surface. The
hand-authored files have exact headers and no exporter quirks.

## W2 — signature detection and gzip fixtures

These files exercise the W2 front door (signature detection + streaming gzip
inflate). All are self-generated.

| File | Kind | Provenance | Notes |
|---|---|---|---|
| gate-p2-star.emz | gzip → EMF | `gzip -9 -n -c gate-p2-star.emf` | `.emz` wrapper of the committed EMF. `-n` omits the original filename and mtime (no name/timestamp leak); the tests assert it inflates byte-identical to `gate-p2-star.emf`. |
| gate-p3-shapes.emz | gzip → EMF | `gzip -9 -n -c gate-p3-shapes.emf` | as above, for `gate-p3-shapes.emf`. |
| gate-p4-text.emz | gzip → EMF | `gzip -9 -n -c gate-p4-text.emf` | as above, for `gate-p4-text.emf`. |
| handmade-wmf-standard.wmf | standard WMF | hand-authored bytes | 24 bytes: a META_HEADER ([MS-WMF] §2.3.2.2; DISKMETAFILE, HeaderSize 9, METAVERSION300) followed by META_EOF. A valid header + EOF is all W2 detection needs; record decode arrives in W3. |
| handmade-wmf-placeable.wmf | placeable WMF | hand-authored bytes | 46 bytes: a META_PLACEABLE ([MS-WMF] §2.3.2.3; key 0x9AC6CDD7, 0–1000 bounding box, 1440 units/inch, checksum 0x52B1) then a MEMORYMETAFILE META_HEADER and META_EOF. The checksum is correct, so detection raises no diagnostic; corrupting it is covered in the tests as a diagnostic, never a rejection. |

The WMF corpus grows in W3/W4 with LibreOffice-exported drawings once the WMF
record walker and renderer land; these two hand-built headers cover W2's
detection path only.

## W3 — WMF record walker corpus (LibreOffice exports)

These exercise the W3 WMFParse header + 16-bit record walker. All are
self-generated: each is a LibreOffice headless export of the matching
self-authored `gate-*.svg` already in this corpus, so no new artwork was
sourced. Exported with LibreOffice 26.8.2.2 on macOS:
`soffice --headless --convert-to wmf gate-<stem>.svg --outdir <scratch>`, then
copied in and renamed `gate-wmf-<stem>.wmf` (the `gate-wmf-` prefix replaces the
original `gate-` prefix, keeping the shared `p2-star`/`p4-text`/… suffix so each
WMF is easy to pair with its EMF/SVG siblings). LibreOffice writes **placeable**
WMFs (Aldus key 0x9AC6CDD7, Inch 2540, MEMORYMETAFILE/METAVERSION300) and
embeds a complete EMF in the first record (META_ESCAPE "WMFC") — that embedded
EMF is played in preference to the GDI records in W4; W3 only walks and accounts
for the records. Every header's `SizeLow/SizeHigh` and `MaxRecord` match the
walk exactly; `NumberOfObjects` is a constant 16 (the exporter's object-table
size, not a creation count). All files are well under 1 MB, and `strings` across
every export shows no username, path, or hostname (checked for `avneet`,
`Users`, `Neet`, `singh`, `/home/`).

| File | Kind | Provenance | Notes |
|---|---|---|---|
| gate-wmf-p2-house.wmf | placeable WMF | `soffice --convert-to wmf gate-p2-house.svg` | house scene; 240 records, MaxRecord 4118 WORDs. |
| gate-wmf-p2-star.wmf | placeable WMF | `soffice --convert-to wmf gate-p2-star.svg` | ten-point star + zigzag; 88 records. |

### WMF-only variants (W4)

Each LibreOffice export above carries a complete embedded EMF, which Emfy plays
in preference to the WMF records. To make the oracle gate exercise the WMF
record-playback path itself, these variants have the
META_ESCAPE_ENHANCED_METAFILE records removed and the META_HEADER
`SizeLow/SizeHigh` and `MaxRecord` re-accounted (the placeable header is copied
unchanged). Generated with the permanent tool, reproducibly:
`emfy-dump --strip-emf corpus/gate-wmf-<stem>.wmf corpus/gate-wmf-gdi-<stem>.wmf`.
emfy-dump's byte accounting equals the file size for each, with zero escapes left.

| File | Kind | Provenance | Notes |
|---|---|---|---|
| gate-wmf-gdi-p2-house.wmf | placeable WMF, no embedded EMF | `--strip-emf gate-wmf-p2-house.wmf` | 2 escapes stripped; 4128 bytes. |
| gate-wmf-gdi-p2-star.wmf | placeable WMF, no embedded EMF | `--strip-emf gate-wmf-p2-star.wmf` | 1 escape stripped; 1612 bytes. |
| gate-wmf-gdi-p2-triangles.wmf | placeable WMF, no embedded EMF | `--strip-emf gate-wmf-p2-triangles.wmf` | 1 escape stripped; 1936 bytes. |
| gate-wmf-gdi-p3-curves.wmf | placeable WMF, no embedded EMF | `--strip-emf gate-wmf-p3-curves.wmf` | 2 escapes stripped; 4508 bytes. |
| gate-wmf-gdi-p3-shapes.wmf | placeable WMF, no embedded EMF | `--strip-emf gate-wmf-p3-shapes.wmf` | 2 escapes stripped; 4374 bytes. |
| gate-wmf-gdi-p4-image.wmf | placeable WMF, no embedded EMF | `--strip-emf gate-wmf-p4-image.wmf` | 1 escape stripped; 640 bytes; META_STRETCHDIB kept. |

Hand-built walker-abuse fixtures (RecordSize 0/1/2, RecordSize past the end,
